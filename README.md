# AI Fitness Coach

A small, fully self-contained Python project that generates a weekly workout
plan from a **rule-based** engine — no LLM, no external API calls, no
network access required. Given a training goal, experience level, training
frequency, and available equipment, it produces a complete weekly split with
specific exercises, sets, reps, and rest periods.

This is a workout-programming tool. It is conceptually distinct from
nutrition/meal-planning projects (e.g. a diet planner) — this project does
not touch diet, calories, or macros at all.

## Methodology

The plan generator is entirely deterministic and stdlib-only:

1. **Exercise database** (`data/exercises.json`): ~60 hand-authored
   exercises, each tagged with a `muscle_group` (chest, back, shoulders,
   quads, hamstrings, glutes, calves, biceps, triceps, core), a required
   `equipment` tier (`bodyweight`, `dumbbells`, `full_gym`), and a `type`
   (`compound` or `isolation`).

2. **Equipment tiers**: equipment is ranked `bodyweight < dumbbells <
   full_gym`. An exercise is eligible for a user only if its required tier
   is at or below what the user has available — a `bodyweight` user is
   never given a dumbbell or gym-machine exercise, while a `full_gym` user
   can be given anything.

3. **Weekly split selection**: the number of training days maps to a fixed
   split template:

   | days/week | split | day sequence |
   |---|---|---|
   | 1 | Full Body | full_body |
   | 2 | Upper/Lower | upper, lower |
   | 3 | Push/Pull/Legs | push, pull, legs |
   | 4 | Upper/Lower x2 | upper, lower, upper, lower |
   | 5 | PPL + Upper/Lower | push, pull, legs, upper, lower |
   | 6 | PPL x2 | push, pull, legs, push, pull, legs |

   Each day type trains a fixed list of muscle groups (e.g. "push" trains
   chest, shoulders, triceps). The templates are constructed so that, for
   every value of days/week, the **union** of muscle groups trained across
   the week covers all 10 tracked muscle groups — no muscle group is ever
   neglected, even on a 1-day-per-week plan.

4. **Sets/reps/rest by goal**:

   | goal | sets (base) | reps | rest |
   |---|---|---|---|
   | strength | 5 | 3-5 | 180s |
   | hypertrophy | 3 | 8-12 | 75s |
   | endurance | 2 | 15-20 | 30s |
   | general_fitness | 3 | 10-15 | 60s |

5. **Volume by experience level**: the base set count from the goal is
   adjusted by level (`beginner: -1`, `intermediate: 0`, `advanced: +1`,
   floored at 2 sets), and `advanced` plans additionally get one bonus
   accessory exercise per training day — so total weekly volume scales
   beginner < intermediate < advanced. Each level also comes with a short
   progression note (e.g. beginners are told to prioritize form before
   adding load; advanced lifters are pointed toward planned overload and
   deloads).

6. **Exercise selection**: for each muscle group on a given day, the
   generator filters the database to equipment-eligible exercises, prefers
   compound movements, and deterministically rotates through the eligible
   list across the week (no randomness) so repeated muscle groups don't
   always get the exact same exercise.

## How to run

Requires Python 3.11+ (stdlib only, no dependencies to install).

```bash
python3 coach.py --goal hypertrophy --level intermediate --days 4 --equipment full_gym
```

Arguments:

- `--goal`: `strength` | `hypertrophy` | `endurance` | `general_fitness`
- `--level`: `beginner` | `intermediate` | `advanced`
- `--days`: integer `1`-`6`
- `--equipment`: `bodyweight` | `dumbbells` | `full_gym`

## Running the tests

```bash
python3 -m unittest discover -s tests -v
```

16 unit tests cover: equipment constraints per equipment tier, sets/reps
differing correctly by goal, split structure matching `days_per_week`,
full muscle-group coverage across every day-count from 1-6 (including
bodyweight-only), beginner-vs-advanced volume scaling, and clear
`ValueError`s on invalid input (e.g. `--days 0` or `--days 8`, unknown
goal/equipment).

## Disclaimer

This project is for **educational and general fitness purposes only**. It
is a simple rule-based tool, not a certified trainer or medical
professional. It does not account for injuries, medical conditions, or
individual biomechanics. Consult a qualified healthcare or fitness
professional before starting any new exercise program.
